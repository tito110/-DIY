# 心理学クイズアプリ

心理学概論の学習を支援するクイズアプリケーションです。

## 特徴

- 📚 **2つの問題セット**
  - 通信指導問題（問1～問10）
  - 自習型問題（Q1～Q10）

- 🎯 **充実した学習機能**
  - 詳しい解説付き
  - ヒント表示
  - 間違えた問題の復習機能
  - 進捗状況の表示

- 💻 **使いやすいUI**
  - レスポンシブデザイン
  - 美しいグラデーション
  - 直感的な操作

## 使い方

### 1. 依存関係のインストール（初回のみ）

```bash
npm install
```

### 2. 開発サーバーの起動

```bash
npm run dev
```

サーバーが起動したら、ブラウザで以下のURLにアクセスしてください：

```
http://localhost:5173/
```

### 3. 本番ビルド（オプション）

```bash
npm run build
```

ビルド後のファイルは `dist` ディレクトリに生成されます。

### 4. ビルドのプレビュー（オプション）

```bash
npm run preview
```

## 機能詳細

### 科目選択
- 心理学概論を選択

### 問題セット選択
- 通信指導問題（提出が必要な問題）
- 自習型問題（復習・練習用）

### 問題回答
- 4択から1つを選択
- 回答後、正誤判定と詳しい解説を表示
- ヒントと解説で理解を深める

### 復習機能
- 間違えた問題を自動的に記録
- 全問終了後、間違えた問題のみを復習可能
